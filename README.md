---

## 🌟 Highlights & Features

- **⚡ Lightweight & Fast**: Pure HTML5 and vanilla CSS3 with zero heavy dependencies or framework bloat.
- **🎨 Premium Dark Theme**: Curated aesthetic with deep blacks (`#050505`), glassmorphic overlays, and subtle crimson red highlights (`#cf4d4d`).
- **📱 Fully Responsive**: Custom fluid grids and typography optimized for mobile devices, tablets, and ultra-wide screens.
- **🚀 Featured Work Showcase**: Card layouts highlighting key SaaS, CRM, IoT, and AI agent projects with tech tags and direct repository links.
- **📊 Proof & Metrics Bar**: Instant credibility stats (`15+ Projects`, `5+ Live Apps`, `3+ Production Systems`).
- **📱 Mobile Quick Action Bar**: Floating bottom bar on mobile with direct **WhatsApp** and **Hire Me** actions.
- **📬 Interactive Contact Form**: Clean form styling ready for Formspree or custom backend endpoints.

---

## 🛠️ Tech Stack & Architecture

- **Markup**: HTML5 (Semantic elements, SEO-optimized meta tags, OpenGraph ready)
- **Styling**: CSS3 (CSS Custom Properties, Flexbox, CSS Grid, Glassmorphism `backdrop-filter`, Smooth Animations)
- **Typography**: [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts
- **Icons**: [Font Awesome 6.5](https://fontawesome.com/)

## 🚀 Getting Started Locally

No build tools, package managers, or bundlers required.

### 1. Clone the repository
```bash
git clone https://github.com/jatinnjangid/portfolio.git
cd portfolio
```

### 2. Run locally
You can open `index.html` directly in your browser:

```bash
# On macOS
open index.html

# Or using Python's built-in local server
python3 -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.
